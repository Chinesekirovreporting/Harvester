## 二、表格数据结构（SkillCFG）

**路径**: `tableClass/$SkillCFG.ts` / `SkillCFG.ts`

| 字段 | 类型 | 说明 |
|------|------|------|
| ID | number | 技能ID |
| Name | string | 技能名称 |
| Type | string | 技能类型（主动/被动等） |
| Desc | string | 技能描述 |
| Cooldown | number | 冷却时间 |
| Cost | number | 消耗 |
| EffectIds | number[] | 效果ID列表 |
| Level | number | 等级 |
| Icon | string | 图标资源名 |

**数据获取**: `App.tableManager.getTables($Tables.SkillCFG)` / `getTable($Tables.SkillCFG, id)`

## 三、开发规范（必须遵循）

### 3.1 窗口类（WindowSkillBook）
- 继承 `AbstractUIWindow`
- 实现 `getResList()` 返回 `["ui/SkillBook"]`
- 在 `onInit()` 中：
  - `UICore.registerExtension("SkillBook", "RenderSkillBook", RenderSkillBook)`
  - `UICore.createObject("SkillBook", "WindowSkillBook").asCom` 创建视图
- 在 `onInitView()` 中获取 `listSkillBook`(GList)、`btnClose`(GButton)，绑定事件
- 列表使用 `setVirtual()` + `itemRenderer` 做虚拟列表
- 在 `onShow()` 中刷新列表数据
- 在 `onDispose()` 中解绑事件、置空引用

### 3.2 数据模型（ModelSkill）
- 继承 `AbstractModel`
- 提供 `getSkillList(): SkillCFG[]`，参考 `ModelHeroBook.getHeroBookList()`
- 使用 `ObjectUtil.objectToArray<SkillCFG>(App.tableManager.getTables($Tables.SkillCFG))`
- 在 `GameModels.init()` 中初始化并挂载到 `GameModels.skill`

### 3.3 列表项渲染器（RenderSkillBook）
- 继承 `GButton` 或 `GComponent`（参考 RenderHeroBook / RenderAchieve）
- 重写 `onConstruct()` 获取子组件
- 实现 `setData(skillCFG: SkillCFG)` 绑定：Name、Type、Desc、Icon、Cooldown、Cost 等

### 3.4 窗口注册
- 在 `ModuleWindow.init()` 的 `_windowClassDict` 中注册：`"WindowSkillBook" = WindowSkillBook`

## 四、FGUI 设计要点

### 4.1 WindowSkillBook 布局
- 参考 `WindowHeroBook` / `WindowAchieve`：标题区、内容区、关闭按钮
- GList 命名为 `listSkillBook`，defaultItem 指向 RenderSkillBook 的 URL
- 可设置 `overflow="scroll"`、`layout` 等

### 4.2 RenderSkillBook 布局
- 建议展示：图标(loader)、名称(lblName)、类型(lblType)、描述(lblDesc)、冷却/消耗(lblCooldown/lblCost)
- 子组件命名与 Render 中 `getChild()` 使用的名称一致
